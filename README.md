# Sprint_10.2

API-автотесты для учебного сервиса «Доска».

Сайт: https://qa-desk.education-services.ru/

## Описание проекта

- urls.py — адрес сервиса и эндпоинты
- data.py — тестовые данные: категории, города, состояния, тексты ошибок
- helpers.py — генерация данных: email, пароль, данные юзера и объявления
- api/user_api.py — методы API для юзера (регистрация, логин)
- api/listing_api.py — методы API для объявлений (создание, редактирование, удаление)
- conftest.py — фикстуры: создание юзера и объявления
- tests/
  - test_registration.py — регистрация юзера (успешная и повторная)
  - test_login.py — авторизация юзера
  - test_create_listing.py — создание объявления
  - test_edit_listing.py — редактирование объявления (своё и чужое)
  - test_delete_listing.py — удаление объявления
- requirements.txt — зависимости проекта
